Fresher Training: Week 1

Oct 26(Monday) -Nov 30(Friday), 2026 ·

This week you will learn the basics of HTML and CSS, and then use them to build the first version of our Task Board project. Everyone learns at a different speed, so go at your own pace, but try to finish the full list by Friday.

Trainer for this week: Yash Dhameliya

Before you start

  1. Chapter 1: Tools And Setup

    1. Installing VS Code, Git Bash and Node.js
    2. VS Code basics: extensions, auto-format, Live Server
    3. Terminal basics: pwd, ls, cd, mkdir
    4. What is Git and why every team uses it
    5. Git commands: git init, git clone, git status, git add, git commit, git push
    6. Writing a clear commit message
    7. Browser DevTools: inspecting elements and editing CSS live

      8. Step 1: Learn the basics

      Start with these. They are enough to begin the project, you don't need to master everything first.

  2. Chapter 2: HTML

    1. What is HTML and how a browser reads it
    2. Structure of an HTML page: doctype, html, head, body
    3. The head section: title, meta charset, meta viewport
    4. Elements, tags and attributes (id, class)
    5. Headings, paragraphs and text formatting
    6. Lists: ordered and unordered
    7. Links and images
    8. Block and inline elements
    9. Semantic tags: header, nav, main, section, article, footer, and why they matter
    10. Non-semantic tags: div and span, and when to use them
    11. Forms: form, input, label, select, textarea, button
    12. Input types and attributes: text, email, password, number, checkbox, placeholder, required
    13. Tables: table, tr, th, td
    14. Accessibility basics: alt text, a label for every input, correct heading order

  3. Chapter 3: CSS Basics

    1. What is CSS
    2. Ways to add CSS: inline, internal, external file (and why external is preferred)
    3. Selectors: element, class, id, grouping, descendant
    4. Pseudo-classes: :hover, :focu
    5. Cascade and specificity: which rule wins
    6. Colours, fonts and text styling
    7. Box model: content, padding, border, margin
    8. box-sizing: border-box
    9. Display: block, inline, inline-block, none
    10. Units: px, %, rem, vw, vh
    11. Position: relative, absolute, fixed, sticky

      12. Step 2: Start building the Task Board

      Now use what you learned. This is a static page only, no JavaScript this week. All tasks are written directly in the HTML.

      • Page structure using semantic tags (header, main, ul, li)
      • Add-task form with a text input, a priority dropdown and an Add button
      • A list of at least 5 tasks, each with a checkbox, title, priority badge and delete button
      • A stats bar showing total, done and high-priority tasks
      • Basic styling: colours, fonts, spacing and coloured priority badges

Final checklist (by Friday)

Before Friday, make sure your page has:

  • A header
  • An add-task form with a text input, a priority dropdown and an Add button
  • A list of at least 5 tasks
  • Each task showing a checkbox, the title, a coloured priority badge and a delete button
  • A stats bar showing total tasks, done tasks and high-priority tasks
  • A simple detail view for one task
  • Semantic tags used properly (header, main, ul, li), not div for everything
  • Works on a mobile screen without horizontal scrolling
  • Pushed to your repo with at least 8 meaningful commits

The buttons and checkboxes don't need to work yet. You will make them work in Week 3.

Rules for this week

  • Stuck on something? Try on your own for 20 minutes and read the error properly. Then write your question clearly (what you expected, what happened, what you tried) and bring it to the next trainer slot. Meanwhile, move on to another part of the work.
  • Commit small and often, not one big commit at the end.

On Friday

  • Show your Task Board to the trainer
  • Give a 5-minute presentation in Gujarati or Hindi: what you built, what you learned and what was difficult
  • Be ready to explain any line of your code
